# Trabajo Integrador - Introducción a Python

## Descripción

Trabajo integrador realizado para el curso **Introducción a Python**.

El proyecto consiste en el desarrollo de dos aplicaciones en Python:

1. Sistema de Tickets.
2. Generador de Contraseñas.

---

## Aplicación 1: Sistema de Tickets

Permite registrar y consultar tickets de soporte mediante un menú interactivo.

### Funcionalidades

* Alta de tickets.
* Generación automática de número de ticket.
* Consulta de tickets por número.
* Menú de navegación.
* Confirmación de salida.

---

## Aplicación 2: Generador de Contraseñas

Permite generar contraseñas seguras de forma aleatoria según el tipo seleccionado por el usuario.

### Funcionalidades

* Generar contraseñas solo de letras.
* Generar contraseñas solo de números.
* Generar contraseñas de letras y números.
* Generar contraseñas de letras, números y caracteres especiales.
* Selección de la longitud de la contraseña.
* Menu de navegación.
* Confirmación de salida.
